## Установка

1. Скачайте ZIP по кнопке выше и распакуйте его.
2. Перенесите **VoiceForge.app** в папку **Программы**.
3. Откройте приложение. При обновлении сначала полностью закройте старую версию через **⌘Q**.

Приложение распространяется без нотариальной проверки Apple. При первом запуске macOS может заблокировать открытие.
Если вы скачали приложение отсюда и хотите его открыть: после попытки запуска перейдите в
**Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**
и подтвердите запуск. [Инструкция Apple](https://support.apple.com/102445).

## Возможности

- Studio Voice — нейросетевая обработка речи.
- Удаление фоновой музыки.
- Ручная обрезка и удаление выделенных фрагментов, масштабирование волны.
- Динамический и десятиполосный графический эквалайзер.
- Компрессор, лимитер и максимайзер.
- Экспорт WAV, M4A/AAC и MP3.

Обработка выполняется на компьютере. При первом использовании удаления музыки
потребуется интернет для загрузки модели (около 84 МБ). Качество обработки зависит от исходной записи.
